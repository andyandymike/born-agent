# Development-only DeepSeek procedure pilot

This frozen fixture defines a three-case, three-pair, six-attempt directional
A/B pilot over heterogeneous boundary and state contracts.
It deliberately does not satisfy the twelve-pair VP0 evaluation contract.

The comparison is procedure-present versus no-memory. It is not the strict VP0
equal-information representation comparison.

The default tool mode is offline. A paid run requires an explicit run-local
remote authorization flag, an explicit cost ceiling, and a self-hashed passing
DS0 observation whose same-run qualification record, actor result, fresh
verification, protocol, pricing, configuration, and complete usage all validate.
An independent qualification descriptor is not accepted. The API key is never
part of this fixture.

The paid actor uses the same restricted production tool surface in both arms:
`list_files`, `read_file`, `apply_patch`, `run_command`, and `finish_task`.
Per-attempt peak-price partitions are 64,000 uncached-input tokens, 4,000
cache-read tokens, 1,300 output tokens, and 69,300 total reported tokens. The
partition is 29,932 micro-USD per attempt and 179,592 micro-USD for all six.

The primary effect outcome is the independent exact fresh verifier. BornAgent's
verified `finish_task` completion is recorded separately as a secondary product
outcome. A DS0 `functional_entry_only` observation may establish qualification
only when its exact patch and fresh verifier passed with complete, matching
backend/session usage and no unsafe or ambiguous action. It is never DS0 product
completion evidence and never itself counts as a pilot quality sample.
