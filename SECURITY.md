# Security policy

BornAgent executes model-directed tools and may interact with local files and
processes. Please report security issues privately so maintainers can assess and
fix them before details become public.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/andyandymike/born-agent/security/advisories/new).
Include the affected version or commit, impact, reproduction steps, and any
suggested mitigation.

Do not open a public issue containing exploit details, credentials, private
prompts, session evidence, or sensitive file contents. If private reporting is
temporarily unavailable, open a public issue asking the maintainer for a private
contact channel without including vulnerability details.

You should receive an acknowledgement within seven days. Timelines for a fix
and coordinated disclosure depend on severity and complexity.

## Supported versions

BornAgent is pre-1.0 and under active development. Security fixes target the
latest commit on the default branch; older snapshots are not separately
maintained.
